## Overview

This randomizer shuffles every item, song, mask, and dungeon reward in Majora's Mask with configurable logic, glitched-logic support, and seed sharing for co-op and race formats.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Majoras Mask Randomizer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Item Shuffle** | Randomize chest contents, song grants, and NPC reward items |
| **Logic Options** | Choose no-glitch, minor-glitch, or full-glitch accessible item pools |
| **Dungeon Randomizer** | Shuffle dungeon entrances and boss reward locations |
| **Seed Sharing** | Export seed strings for race coordination and async multiworld |
